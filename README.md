## Описание
Программный комплекс автоматизированного управления синхронной съемкой, калибровкой массива камер и входным контролем качества наборов снимков в фотограмметрической студии для создания 3D-ассетов игровой индустрии.

## Структура репозитория
- `docs/` — материалы отчета и проектная документация практики;
- `python/` — алгоритмы экспресс-валидации резкости, экспозиции и перекрытия кадров;
- `java/` — объектно-ориентированное ядро студии и управление сессиями;
- `db/` — схема и миграции базы данных PostgreSQL;
- `vcs/` — служебные выгрузки истории коммитов.
